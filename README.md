# Customer Churn Prediction & Business Insights Using Machine Learning

## Project Overview

This project predicts customer churn using Machine Learning techniques and analyzes customer behavior to generate business insights.

## Objective

To identify customers who are likely to leave a company and help businesses improve customer retention.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Machine Learning Algorithms

* Logistic Regression
* Random Forest Classifier

## Project Steps

1.Load Dataset
2. Data Cleaning
3. Exploratory Data Analysis
4. Customer Churn Analysis
5. Prepare Data for Machine Learning
6. Separate Features and Target
7. Split Dataset
8. Train Logistic Regression Mode
9. Predict Customer Churn
10.Check Model Accuracy
11.Classification Report
12. Confusion Matrix
13. Random Forest Model
14. Compare Model Accuracy
15. Feature Importance Analysis
16. Calculate Customer Churn Percentage
17. Predict Churn for a Custome
18. Business Insights
19. Final Business Insights

## Project Outcome

The project uses Machine Learning to predict customer churn and identify customer retention patterns.

It helps businesses understand customer behavior and make data-driven decisions to improve customer retention.
